# Bundled receiver tensors

`LN_single_spot_receiver_tensors.mat` contains `TM_01_tensor`, the 400 complex receiver tensors used for Fig. 1e,f. The array has 1,296 rows (36 × 36 coefficients per tensor) and 400 columns.

Source: Daixuan Wu and Zhen Yi, *Referring Code and Data of “Inverse theory of wavefront shaping in nonlinear scattering media”*, Zenodo, version 2, [10.5281/zenodo.19246102](https://doi.org/10.5281/zenodo.19246102). The source file is `refering data/nonlinear wavefront focusing/LN_single_spot.mat` inside `refering data.zip`.

We extracted `TM_01_tensor` and saved it in a compressed MATLAB file. The values, precision and order are unchanged. The SHA-256 of the array encoded as little-endian complex128 in C order is `b1e4996355166c740e0116bffea046d744e5038b4e912a6b458b47584487c215`.
